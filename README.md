# Card Issuance Service

Сервис для подачи и обработки заявок на выпуск банковских карт.

## О проекте

Card Issuance Service — учебный pet-проект, имитирующий часть банковской системы. Приложение предназначено для создания заявок на выпуск банковских карт и отслеживания их обработки.

Проект разрабатывается с целью изучения Java backend-разработки, проектирования REST API, работы с базами данных и построения надёжных сервисов.

## Основные возможности

На текущем этапе функциональность находится в разработке.

Планируемые возможности:
- Создание заявки на выпуск банковской карты.
- Хранение заявок в базе данных.
- Получение информации о заявке.
- Валидация входящих данных и обработка ошибок.
- Асинхронная обработка заявок.
- Интеграция с Apache Kafka.
- Повышение надёжности обработки сообщений с помощью Retry, Dead Letter Queue (DLQ) и идемпотентности.

## Архитектура

Приложение спроектировано по классической многослойной архитектуре. Компоненты разделены по зонам ответственности:

* **`HealthController`** — контроллер веб-слоя (REST API), который обрабатывает входящие HTTP-запросы проверки доступности и работоспособности сервиса.
* **`CardApplicationService`** — сервисный слой, предназначенный для инкапсуляции бизнес-логики работы с заявками на выпуск карт.
* **`CardApplicationRepository`** — слой доступа к данным (Data Access Object), обеспечивающий взаимодействие с базой данных PostgreSQL через Spring Data JPA.
* **`CardApplication`** — слой сущностей (Domain Entity), представляющий структуру таблицы заявки в базе данных.

### Сущность `CardApplication`
Представляет собой заявку на выпуск банковской карты и содержит следующие ключевые поля:
* **Идентификатор (`id`)** — уникальный номер заявки, генерируется автоматически базой данных.
* **Имя заявителя** — имя и фамилия пользователя, подавшего заявку.
* **Тип карты** — категория запрашиваемой карты (например, дебетовая или кредитная).

## Локальная настройка

Для локального запуска приложения необходимо:
1. Создать базу данных в PostgreSQL с именем `card_issuance_db`.
2. Подключиться к СУБД по адресу: `localhost:5432` (или вашему стандартному локальному адресу хоста).
3. Перед запуском приложения задать следующие переменные окружения (**Environment variables**):
    * `DB_USERNAME` — имя пользователя.
    * `DB_PASSWORD` — ваш локальный пароль от базы данных.
