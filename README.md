# Card Issuance Service

Сервис для подачи и обработки заявок на выпуск банковских карт.

## О проекте

Card Issuance Service — учебный pet-проект, имитирующий часть банковской системы. Приложение предназначено для создания заявок на выпуск банковских карт и отслеживания их обработки.

Проект разрабатывается с целью изучения Java backend-разработки, проектирования REST API, работы с базами данных и построения надёжных сервисов.

## Основные возможности

На текущем этапе функциональность находится в разработке.

Планируемые возможности:
- Создание заявки на выпуск банковской карты.
- Хранение заявок в базе данных.
- Получение информации о заявке.
- Валидация входящих данных и обработка ошибок.
- Асинхронная обработка заявок.
- Интеграция с Apache Kafka.
- Повышение надёжности обработки сообщений с помощью Retry, Dead Letter Queue (DLQ) и идемпотентности.

## Технологический стек

Планируемые технологии:
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- Maven
- JUnit 5
- Mockito
- Docker
- Apache Kafka
- Git и GitHub

Технологии будут подключаться постепенно по мере развития проекта.

## План разработки

1. Создание REST API и подключение PostgreSQL.
2. Валидация данных, обработка ошибок, unit-тесты и Docker.
3. Асинхронная обработка внутри приложения с помощью `@Async`.
4. Интеграция Apache Kafka.
5. Реализация Retry, Dead Letter Queue и идемпотентности.

## Статус проекта

**В разработке.** Каркас Spring Boot создан и успешно запускается на локальном порту 8080.

## Цель

Создать законченный pet-проект для портфолио, демонстрирующий навыки Java backend-разработки, проектирования API, работы с PostgreSQL, тестирования и обработки асинхронных задач.
